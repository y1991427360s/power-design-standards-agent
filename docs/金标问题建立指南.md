# 金标问题建立指南

第一阶段由电气设计工程师建立 50 个真实工作问题，稳定后扩展至 100～300 个。仅导入具有合法使用权限的规范，原文留在私有资料库；不要将 PDF 或保密工程问题放入公开仓库。

覆盖电气一次、电气二次、继电保护、控制电缆、直流系统、通信、调度自动化、IEC 61850、站控层、间隔层、过程层。按真实工作频率分配，并保留跨专业、同义表达、口语表达、指定规范、多规范和无依据问题。IEC 61850 等分类只是标签，不能自动认定该规范已收录。

每题人工确认正确规范名称、编号、版本、条号、原文页码、适用条件及例外；核对资料合法来源和现行状态。第二位工程师复核，分歧记录于 notes，不强行给出工程结论。一个证据需要有多个可接受条文时，用 clause_groups 标注允许替代；需要同时找到多个规范时建立多个必需组。

无依据题必须相对于当前完整资料库确认：包括未收录的指定规范、相近主题但限定条件不支持的问题、仅存在历史经验/厂家资料的情况。不能仅因工程师不知道答案就标 negative。新增规范后重新核验负题标签。

模板（真实题在仓库外保存；以下占位内容须替换后才能评测）：

```json
[
  {
    "id": "SEC-001",
    "question": "控制电缆屏蔽层应如何接地？",
    "domain": "控制电缆",
    "expected_documents": [{"standard_code": "人工核验编号", "version": "人工核验版本"}],
    "expected_clauses": [{"standard_code": "人工核验编号", "version": "人工核验版本", "clause": "人工核验条号"}],
    "expected_keywords": ["屏蔽", "接地"],
    "negative": false,
    "applicable_conditions": "填写电压等级、范围、例外与页码；不要推断原文没有的条件",
    "notes": "标注人、复核人、日期、授权来源及争议"
  }
]
```

先通过现有网页上传合法资料，检查解析后的条文与页码，确认元数据并设置现行状态。建立私有评测库，排除 DEMO，备份 SQLite 后运行离线快照评测。编号、版本必须与库中一致，缺失金标会报错。保存数据集版本、代码版本、库指纹和报告；同一组冻结问题与资料库用于比较优化，另留未用于调参的验收题，避免针对测试集过拟合。

检查失败题的前 10 条结果与评分：正确条文未解析先修 Parser；同义/口语召回弱先评估 Embedding/Query Rewrite；已经召回但排序靠后再评估 Reranker。不能凭综合分数证明条文适用性，工程结论仍须人工核对。
