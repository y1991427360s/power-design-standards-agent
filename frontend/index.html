系统设置

模型与数据发送

在项目根目录的 .env 文件配置，修改后重启服务。API Key 不在网页中展示或保存。

ALLOW_EXTERNAL_API=false
LLM_BASE_URL=https://your-provider/v1
LLM_API_KEY=
LLM_MODEL=
EMBEDDING_PROVIDER=local
EMBEDDING_BASE_URL=https://your-provider/v1
EMBEDDING_API_KEY=
EMBEDDING_MODEL=
TOP_K=10

开启外部 API 后，远程 Embedding 会收到导入条文和查询；可选 LLM 会收到问题和候选条文。请确认资料允许发送后再开启。local 为离线概念归一化哈希向量，语义能力有限；更换向量模型后须重新解析全部资料。

V1 仅监听本机，无多人权限系统。知识库和聊天保存在 knowledge/storage，备份时应包含数据库与 files 目录。
